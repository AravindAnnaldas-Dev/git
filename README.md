# Git

Git is a distributed version control system for tracking changes to files and coordinating work across projects.

## Getting Started

Install Git from [git-scm.com](https://git-scm.com/), then configure your identity:

```bash
git config --global user.name "Your Name"
git config --global user.email "you@example.com"
```

## Common Commands

```bash
git init                 # Initialize a repository
git clone <url>          # Copy a repository
git status               # Check the working tree
git add <file>           # Stage changes
git commit -m "message"  # Save staged changes
git pull                 # Fetch and integrate updates
git push                 # Publish local commits
```

## Documentation

For guides and reference documentation, visit [git-scm.com/doc](https://git-scm.com/doc).
